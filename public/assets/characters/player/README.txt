Notes
  - Root motion on: walk/run/strafe clips move the hips forward or sideways instead of playing in place.
  - Looping clips are named "…-loop", which Godot imports as looping automatically.
  - The assault rifle is skinned to the WeaponR bone (child of the right hand). To swap weapons in-engine, export it as a separate file and attach props to WeaponR.
  - Clip files hold only the skeleton + animation (Unity "model@clip" convention): import the model first, then the clips onto its skeleton.

Conventions: +Y up, character faces +Z. GLB/OBJ in metres, FBX in centimetres.
Game rigs use Mixamo bone names (Hips, Spine, LeftArm...), so Mixamo / Unity Humanoid / Unreal retargeting maps them automatically.
